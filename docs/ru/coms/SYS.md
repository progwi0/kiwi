<div align="center">
    <h3>sys</h3>
</div>

`sys` это команда для вызова команд вашей операционной системы. Создана для того, чтобы вызвать несуществующую в языке команду.

**Использование**: `sys` *[Ваша команда]*
<br />
**Замены**: *пока не существует*

Пример:

```kiwi
sys echo "Hello, World!"
```

**Результат**:
```
Hello, World!
```
