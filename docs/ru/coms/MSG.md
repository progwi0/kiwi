<div align="center">
    <h3>msg</h3>
</div>

`msg` это команда для вывода сообщений в терминал, и в **Начало** она показана как самая первая.

**Использование**: `msg` *[Ваш текст вывода]*
<br />
**Замены**: `sys` **echo** "*[Ваш текст вывода]*"

Пример:

```kiwi
msg Привет, мир!
```

**Результат**:
```
Привет, мир!
```
