<div align="center">
    <h3>Переменные</h3>
</div>

Переменная это ячейка в памяти компьютера, имя и значение которой можно менять в любое время. Если вы ничего не поняли, то тогда подойдём по-другому.

Представим что у вас есть шкафчик с вашим именем, и вы туда можете сложить вещи. Переменная это что-то подобное.

Чтобы объявить переменную в **Python**, особо ума вам не нужно:

```py
name = "John"
```

Это переменная `name` с значением `John`. Вы можете её вывести, но это не суть, это не урок по **Python** в конце концов.

А чтобы объявить переменную в **Kiwi**, вам нужно немного больше усилий:

```kiwi
set name John
```

Итак, как вы догадались, чтобы объявить переменную в **Kiwi** вам нужно написать команду `set`. Далее, после неё вам нужно написать название переменной, тут: `name`, а затем вам нужно написать само значение, тут: `John`.

Чтобы вывести значение этой самой переменной, вам достаточно просто:

```kiwi
out name
```

Возможно вы спросите: почему не `msg`? А потому что `msg` не поддерживает вывод переменных, вот и всё.
