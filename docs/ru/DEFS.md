    <h3>Макросы</h3>
</div>

Макрос это правило текстовой подстановки, которое связывает название с фрагментом кода (в **Kiwi** - командой).

## Создание

Чтобы создать макрос, вам достаточно написать команду `def`:

```kiwi
def helloworld msg Hello, World!
```

Итак, идём по порядку. Наша команда это `def`, **главное** слово, без него не обойтись, следующее - `helloworld`, это название нашего макроса, по нему мы можем его вызвать, и далее уже идёт сама команда, тоесть тут: ``msg Hello, World!``.

Вы не ограничены названиями и командами, любая команда в макросе заработает как будто она просто введена. Хотя с названиями есть сомнения, вряд-ли ваш макрос заработает, если у него название `msg` или `set`.

## Запуск

Итак, у вас есть 2 варианта запуска макросов. Первый, самый простой, это просто введя его название:

```kiwi
helloworld
```

А есть второй, более сложный, написав команду `run`:

```kiwi
run helloworld
```

Результат:

```
Hello, World!
```

Оба выполняют свою функцию одинаково, разницы нет.

## Аргументы

Также, у макросов могут быть аргументы. Чтобы создать макрос с аргументами, вам не нужно писать ничего сложного:

```kiwi
def helloworld msg Hello, a1
```

Да-да, это просто обычный `def`! Единственное отличие - это вот этот `a1`. Так что же он значит?
А он значит, что он первый аргумент! Если бы было `a2`, то это был бы второй аргумент, и так по порядку.

И чтобы вызвать наш желанный макрос с аргументом, просто введите:

```kiwi
helloworld John
```

Или по-старинке:

```kiwi
run helloworld John
```

Результат:

```
Hello, John
```

## Конец
