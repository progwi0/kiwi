<div align="center">
  <h3>Overview</h3>
</div>

Kiwi is a programming language that is extremely simple to learn and understand, created specifically for absolute beginners.
All code written in it is perfectly clear, as it appears and executes line by line (one line equals one command).

This language was created specifically for beginners—people who know nothing about programming - which is something very much needed these days.

<div align="center">
  <h3>How was it created?</h3>
</div>

My friends don’t know the first thing about programming or computers, and I had a brilliant idea: to create a programming language that anyone can understand - one that would allow even those with no background in computing to grasp the concepts and write code.
